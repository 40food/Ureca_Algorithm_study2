## 💡 문제 설명
<!--문제에 대한 간단한 요약 (내가 이 문제를 얼마나 파악하고 있는지 확인)-->

- 1번 문제부터 마지막 문제까지의 정답 배열 제공
- 1~3번이 찍는 방식 제공
  - 1번: 1, 2, 3, 4, 5 반복
  - 2번: 2, 1, 2, 3, 2, 4, 2, 5 반복
  - 3번: 3, 3, 1, 1, 2, 2, 4, 4, 5, 5 반복
- 가장 많은 문제를 맞힌 사람이 누구일지 배열에 담아 return

---

## 🚀 접근 방법
<!--
- 어떤 방식으로 접근했는지
- 왜 이 알고리즘을 선택했는지
- 핵심 로직
-->

- 각 사람이 찍는 방식을 배열로 정리
- 카운트를 따로 두고 카운트가 개수를 채우면 0으로 초기화해서 다시 체크
- 배열을 훑으며 문제가 맞았는지 아닌지 카운트하고 가장 큰 사람(같을 경우 같이) 배열에 넣음
