## 💡 문제 설명
<!--문제에 대한 간단한 요약 (내가 이 문제를 얼마나 파악하고 있는지 확인)-->

- 모든 트럭이 다리를 건너는 데 몇 초가 걸리는지 return
- 트럭 올라갈 수 있는 길이: bridge length
- 다리가 버티는 하중: weight
- 트럭이 나감과 동시에 들어올 수 있음에 주의

---

## 🚀 접근 방법
<!--

- 남은 트럭이 없을 때까지 while문 동작
- 초수 증가하며 다리 건넘
- 트럭들은 queue에 넣음-하중 때문에 못 넣을 경우 0 넣음
