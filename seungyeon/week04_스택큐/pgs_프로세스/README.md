## 💡 문제 설명
<!--문제에 대한 간단한 요약 (내가 이 문제를 얼마나 파악하고 있는지 확인)-->

- 우선순위 순으로 실행
- ex) ABCD(2,1,3,2) > C-DAB(2,2,1) > CDAB
- 몇 번째로 실행되는지 알고 싶은 프로세스의 위치를 줌
- 프로세스가 몇 번째로 실행되는지 return

## 🚀 접근 방법
