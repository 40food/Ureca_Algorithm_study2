---

## 🚀 접근 방법
<!--
- 어떤 방식으로 접근했는지
- 왜 이 알고리즘을 선택했는지
- 핵심 로직
-->

- 숫자들의 앞자리만 잘라서 큰 순서대로 정렬
- 같을 경우 뒷자리 없음>뒷자리 큼 순서대로 정렬
- 정렬한 숫자들을 붙이고 string return

수정
- 첫째자리 비교하고 다음 자리 조건에 맞춰 비교하고... 이거 너무 복잡함
- 그냥 두 수를 합쳐봐서 더 큰 쪽으로 정렬하도록 함
- `주의!` sort의 return을 a-b로 하면 비교한 의미가 없다.(결국 a에서 b를 뺀 걸로 정렬함) 조건에 맞춰 1이냐 -1이냐로 return할 것.

수정2
- 0이 있을 경우가 있으므로 값이 0이면 0만 출력하도록 추가 처리 필요
- a와 b가 같다고 해서 a가 크다고 얼버무리면 안 됨!
  >삽입 정렬을 진행하며 방금까진 a가 컸는데 이번엔 b가 커지는 상황 발생
  ><br>= 두 요소의 교환을 무한히 반복하거나 갈 범위를 못 계산해서 터짐!!
- 그래서 두 원소가 같을 땐 0을 return해서 표시
- 혹은 int로 바꾸지 않고 문자열 compareTo를 리턴해도 됨(이게 더 깔끔할듯)
