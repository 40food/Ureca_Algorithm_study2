## 💡 문제 설명
<!--문제에 대한 간단한 요약 (내가 이 문제를 얼마나 파악하고 있는지 확인)-->

- 전화번호 목록을 줌
- 한 전화번호가 다른 전화번호의 접두사면 false
- 접두사 없으면 true

---

## 🚀 접근 방법
<!--

- 핵심 로직

- 배열 정렬
- for문을 돌며 다음 것과 비교
  - 접두사 순서로 정렬되어있으므로
- true로 초기화
- false가 될 경우 바로 for문 break
