## 💡 문제 설명
<!--문제에 대한 간단한 요약 (내가 이 문제를 얼마나 파악하고 있는지 확인)-->

- 섞은 음식=가장 맵지 않은 스코빌 지수+(다음으로 맵지 않은 스코빌 지수*2)
- 모든 음식의 스코빌 지수가 k 이상이 될 때까지 반복
- 최소 횟수 출력

---

## 🚀 접근 방법
<!--
- 어떤 방식으로 접근했는지
- 왜 이 알고리즘을 선택했는지
- 핵심 로직
-->

- 우선순위 큐에 스코빌 점수들을 넣음
- 앞의 두 개를 빼고
- 가장 앞에 있는 것+다음으로 있는 것*2를 해서 새로 넣음
- 가장 앞에 있는 것이 k를 넘으면 종료
- `불가능한 경우가 있음` 음식 스코빌이 k 미만인데 더할 음식이 없는 경우 answer는 -1
  - while 조건을 queue 맨 앞이 k 미만일 때로 지정
  - 지금 음식을 뽑고 다음 음식이 없는 경우 -1로 치고 break
